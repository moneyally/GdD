# K. UI/UX / Localization / Accessibility

## 62. Mobile UI Principles

- 한 손/양손 터치 지원
- 핵심 정보 계층화
- Safe Area 대응
- 작은 화면에서 숫자와 상태의 가독성
- 빠른 Lobby -> Mission 진입
- 긴 입력 최소화
- 네트워크 지연 상태를 명시

## 64. Localization

| Domain | Policy |
|---|---|
| Text | Localization Key 기반, 문자열 하드코딩 금지 |
| Voice | Locale별 선택 다운로드 |
| UI | Text expansion / truncation QA |
| Assets | 문화권별 필요한 리소스 분리 |
| Dates/Currency | Locale-aware formatting |
| Names | Player/NPC naming 정책 |
| Store | Store metadata 번역 별도 관리 |

## 65. Accessibility

- 텍스트 크기 옵션
- 색상만으로 상태 표현하지 않기
- 색약 모드
- 화면 흔들림/플래시 조절
- 자막/음성 텍스트
- 터치 영역 최소 크기
- 진동 강도 옵션
- UI 스케일링
- 고대비 모드
- 컨트롤러 지원
