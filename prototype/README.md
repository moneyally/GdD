# prototype/ — 웹 프로토타입

## `holo-gates.html`

차원문 등반 서바이벌. 브라우저에서 파일을 열면 바로 돌아간다 (빌드 없음, 의존성 없음).

아티팩트로도 배포되어 있다. 소스를 여기 두는 이유는 **버전 관리와 diff**다 —
밸런스 수치를 만졌을 때 무엇이 바뀌었는지 봐야 한다.

### 이 파일이 담고 있는 것

- 판단 엔진 전체 (L0 → L2 GOAP → L1) — `src/decision/`과 같은 공식
- 차원문 3종 · 위상압 · 유한 보급 3종 · 잔상(Echo) 메타
- 순차 관측 연출, 홀로그램 UI

### 주의: 규칙이 두 곳에 있다

이 파일의 판단 로직은 `src/decision/`의 **복제**다. TypeScript 모듈을 그대로 import할 수
없어서(단일 HTML 파일 제약) 손으로 옮겼다.

그래서 규칙을 바꾸면 **양쪽을 같이 고쳐야 한다.** 어느 한쪽만 고치면 프로토타입과
엔진이 갈라진다. 장기적으로는 빌드 단계를 두어 `src/`에서 번들링하는 것이 맞다 —
지금은 재미 검증이 우선이라 복제를 감수했다.

`src/mission/gates.ts`가 차원문을 엔진 쪽에 구현한 것이며, 밸런스 수치는 그쪽이 기준이다.
